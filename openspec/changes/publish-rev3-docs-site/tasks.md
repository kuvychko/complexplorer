## 7. Decisions taken during implementation

- [x] 7.1 **Notebooks are linked, not embedded.** They carry stored outputs (26 MB of `.ipynb`),
  nothing on the site linked to them, and serving them hands them to `mkdocs-jupyter`, whose
  conversion emits warnings that fail the strict build. The design's open question is resolved in
  favour of linking to GitHub. Embedding them later is a deliberate choice, not a missing step.
- [x] 7.2 **`docs/pyvista_usage_guide.md` moved to `docs/internal/`.** Its installation section
  described the optional-PyVista world that ended at 3.0, and its headline claim ("15-30x faster")
  is one C6 was going to have to soften. Its usable content is covered by
  `guide/three-dimensions.md` and the API reference. C6 therefore has one less file to fix.
- [x] 7.3 **`docs/README.md` folded into `docs/index.md` and removed**, and `docs/cli.md` removed
  in favour of `guide/cli.md`. Both were superseded hub pages carrying stale claims ("330+ tests",
  three subcommands); git history keeps them.
- [x] 7.4 **`docs/gallery/README.md` is excluded from the site** rather than rewritten: it
  introduces the folder to someone browsing the repository, and the site has `index.md` and the
  generated gallery page for that job.
