    Domains¶

    A domain is the region of the plane that gets sampled. See the guide for how they compose.

    complexplorer.Domain ¶

    Domain(real: tuple[float, float], imag: tuple[float, float], square: bool = True)

    Bases: ABC

    Abstract base class for complex domains.

    A domain represents a region in the complex plane defined by a membership function. The domain can generate meshes for visualization and supports set operations (union, intersection).

    Attributes:

    Name Type Description
    window_real tuple[float, float]

    Left and right bounds of the viewing window.
    window_imag tuple[float, float]

    Bottom and top bounds of the viewing window.
    square bool

    Whether to constrain the viewing window to be square.

    Initialize domain with viewing window.

    Parameters:

    Name Type Description Default
    real tuple[float, float]

    Left and right edges of the viewing window.

    		 required
    imag tuple[float, float]

    Bottom and top edges of the viewing window.

    		 required
    square bool

    If True, constrain viewing window to be square.

    		 True

    contains ¶

    contains(z: ndarray) -> np.ndarray

    Check if points are inside the rectangle.

    Membership is defined by the rectangle's own re_length/im_length about its center — independent of any square-padding applied to the viewing window for display (so a non-square rectangle does not report the padded strips as inside).
