    Colormaps¶

    How a complex value becomes a colour. Reading a phase portrait covers choosing between these, including measured colour-vision-deficiency behaviour.

    Bases: BasePhasePortrait

    Pure OKLAB phase colormap with optional enhancement.

    Implements a perceptually uniform phase portrait using the OKLAB color space. Maps complex phase directly to OKLAB hue angle while maintaining consistent lightness and chroma. Supports enhanced phase/modulus visualization through sawtooth modulation.

    Parameters:

    Name Type Description Default
    phase_sectors int

    Number of phase sectors for enhancement.

    		 None
    r_linear_step float

    Linear modulus step for contours.

    		 None
    r_log_base float

    Logarithmic base for modulus contours.

    		 None
    auto_scale_r bool

    Auto-calculate r_linear_step for square cells.

    		 False
    scale_radius float

    Reference radius for auto-scaling.

    		 1.0
    enhanced bool

    If True, use sawtooth modulation for better structure visibility. If False (default), use smooth OKLAB colors similar to cplot.

    		 False
    L float

    Base lightness in OKLAB space (0 to 1). Default is 0.7.

    		 0.7
    C float

    Chroma (saturation) in OKLAB space (typically 0 to 0.4). Default is 0.35.

    		 0.35
    v_base float

    Base value for enhanced mode, in [0, 1). Default is 0.5.

    		 0.5
    emphasize_unit_circle bool

    If True, emphasize the unit circle |z|=1.

    		 False
    unit_circle_strength float

    Strength of unit circle emphasis (0 to 1).

    		 0.3
    phase_offset float

    Phase rotation offset in radians. Default is 0.8936868*π to match cplot's color mapping (green for arg=0, blue for arg=π/2, orange for arg=-π/2, pink for arg=π).

    		 0.8936868 * pi
    out_of_domain_hsv tuple

    Color for out-of-domain points.

    		 OUT_OF_DOMAIN_COLOR_HSV
    Notes

    The OKLAB color space provides perceptually uniform color gradients, meaning equal steps in the color values correspond to equal perceptual differences. This is particularly useful for accurate interpretation of complex function behavior.

    When enhanced=True, the colormap uses sawtooth functions to create discontinuous edges at phase and modulus boundaries, dramatically improving the visibility of mathematical structures.
